SubZip Privacy Policy

Effective date: May 30, 2026

SubZip is a local file manager and ZIP utility. This policy explains how SubZip handles user and device data.

1. Data We Collect

SubZip does not collect personal data on remote servers.

SubZip processes and stores data locally on your device, including:

  • Files and folders you choose to view, compress, extract, rename, move, copy, delete, or convert.
  • App preferences such as theme, color choices, and favorites.
  • Task progress information used to show local operation status and notifications.

2. Permissions We Use

  • All files access / storage permissions: used to browse and manage files and folders you select.
  • Notification permission: used to show file operation progress and completion messages.
  • Install packages permission: used only when you explicitly open an APK file and trigger Android installer flow.

3. How Data Is Used

Data is used only to provide core app functionality on your device:

  • ZIP archive creation and extraction
  • File and folder management
  • Local format conversion features
  • User interface preferences and status notifications

4. Data Sharing and Selling

SubZip does not sell personal data and does not share personal data with advertising networks or third-party data brokers.

5. Data Retention and Control

Data remains on your device unless you delete it. You can clear app data from Android system settings, and you can remove files managed by the app at any time.

6. Children’s Privacy

If your audience includes children under 13, this policy still applies: SubZip does not knowingly collect personal information from children and does not use behavior-based advertising.

7. Security

SubZip is designed to process files locally. You are responsible for device-level security and for the files you choose to open or share.

8. Changes to This Policy

We may update this policy over time. Updates will be posted on this page with a revised effective date.
